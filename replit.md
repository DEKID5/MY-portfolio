# Seth Lokou - Personal Portfolio

A modern, responsive portfolio built with Vite, React, TypeScript, and Tailwind CSS.

## Run the app

```bash
npm run dev
```

The dev server starts on port 5000 and is visible in the Replit preview pane.

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Stack

- React 19
- TypeScript
- Vite 6
- Tailwind CSS 4
- Framer Motion / Motion
- Lucide React

## User preferences

- Design style: Jayden portfolio template (black background, orange-red accents, Rajdhani font, left sidebar, right floating nav, offset main content).
- Content source: `src/data.ts` (keep all existing content intact).
